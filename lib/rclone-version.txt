# The rclone the desktop apps BUNDLE, pinned by version and checksum.
#
# Both release build jobs download from https://downloads.rclone.org/v<VERSION>/
# and verify the SHA256 BEFORE unzipping. CI pulling an unverified binary into a
# shipped artifact would be a supply-chain hole, not a convenience -- and pinning
# it here makes an rclone upgrade a visible, reviewable commit rather than
# "whatever was current the day the tag was pushed".
#
# To bump: pick a version, take its two lines from
#   https://downloads.rclone.org/v<VERSION>/SHA256SUMS
# and update all three values below.
#
# Only the GUI builds bundle it. The CLI tarball cannot (one tarball, two
# architectures) and uses the system rclone; detect_rclone in lib/cloud.sh
# searches bin/rclone first and falls through to the system one, so both work
# with no configuration.
